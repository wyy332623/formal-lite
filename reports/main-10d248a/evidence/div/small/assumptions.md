# div contract

- DUT: actual CPU `div.v`, 32-bit operands/results, one `div_clk`. Fixed commit/hash in source.json.
- Active-low synchronous reset, required for the first two sampled edges. Later reset is arbitrary, including during a transaction. `cancel` is arbitrary with priority over launch and final iteration.
- One operation at a time. External model accepts `request && !running && !held && resetn && !cancel`. There is no ready pin. A request presented while busy or while holding completion is ignored.
- After the acceptance edge, 32 iteration edges produce completion/results (visible at the next sampled edge). Results and complete stay held while request stays high; request low clears complete. Dropping request while busy does NOT cancel; cancel/reset do. No assumption requires stable request, operands or signedness during computation.
- Full arithmetic oracle uses unsigned magnitude `/` and `%`, then restores signs. Signed quotient truncates toward zero and remainder has dividend sign. Division by zero returns quotient 0xffffffff and original dividend as remainder. Signed INT_MIN/-1 wraps quotient to 0x80000000, remainder zero. These edge semantics describe this RTL contract, not an ISA-wide claim.
- `control` proves completion timing, cancellation/reset and result stability without an arithmetic oracle. It includes finite 32-cycle progress for an uncancelled/unreset operation; no external fairness is needed. It does NOT prove computed values.
- `bmc` / `prove` enable full-width arithmetic. `small` restricts only accepted operands to unsigned 8-bit or sign-extended signed 8-bit, while retaining the full DUT. `zero` restricts accepted y=0; `unit` restricts accepted y in {1, 0xffffffff}, with arbitrary full-width x/signedness. Input-domain passes cannot establish full-domain correctness.
- `cover` uses CONTROL_ONLY for control reachability. `arithmetic_cover` checks arithmetic reachability separately; failures/timeout are reported as such. No correctness constraints on DUT outputs/internal state are assumed.
- `fault` flips the observed quotient bit only when complete under ZERO_DIVISOR. It must FAIL with a waveform; it is a checker sensitivity test.
- `corners` / `corner_cover` use one constant, symbolic selection among eight explicitly tabulated input/result pairs: signed -7/3, 7/-3, INT_MIN/-1, INT_MIN/1; unsigned UINT_MAX/0x80000000, UINT_MAX/2; signed -7/0 and unsigned UINT_MAX/0. Only these operand pairs are covered; reset/cancel/request timing remains arbitrary. Every vector has a completion cover to rule out vacuous success. The literal quotient/remainder table replaces the expensive general `/` oracle ONLY in these tasks.
